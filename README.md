# 🛒 MarketHub

MarketHub is a production-ready full-stack **Multi-Vendor Marketplace** built with **React**, **TypeScript**, **Django REST Framework**, and **PostgreSQL**. The project is designed to simulate a real-world e-commerce platform where multiple vendors can manage their own stores and products, while customers can browse, purchase, and review products through a modern and responsive web application.

This project is being developed using industry-standard practices with a feature-by-feature workflow, focusing on scalable architecture, clean code, reusable components, and secure REST APIs.
